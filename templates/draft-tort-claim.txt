CLAIM AGAINST A PUBLIC ENTITY
California Government Code sections 910-913.2

================================================================
WARNING -- READ THIS FIRST

YOU MUST FILE THIS CLAIM WITHIN 6 MONTHS OF THE DATE OF THE
INCIDENT. This is a hard legal deadline. If you file even one day
late, your claim is barred and you lose the right to sue the public
entity for money damages. Do not wait. File first, gather more
evidence later if you must.

If the 6-month deadline has already passed, you may file a separate
"Application for Leave to Present a Late Claim" (Gov. Code section
911.4), but it is only granted in limited circumstances. Do not rely
on it -- file on time.
================================================================

INSTRUCTIONS: Send the original to the public entity's governing board
or clerk (see agency's website for the claims address). Keep one
stamped or mailed copy for yourself. Send by a trackable method
(certified mail with return receipt, or hand-deliver and get a
date-stamped copy). The agency has 45 days to act; if it does nothing,
the claim is deemed rejected on day 45, and you then have 6 months
from the rejection to file a lawsuit.

FILING NOTES: File with the clerk or governing board of the public
entity -- NOT with the court. Each public entity has its own claim
form and address; many post them online. If the entity has its own
official claim form, use theirs and attach this as a supplement if
needed. Keep proof of delivery (certified mail receipt or stamped
copy). Calendar two dates: 45 days after filing (deemed rejection if
no response) and 6 months after rejection (deadline to file suit).
