# Templates — backend, assistant-only reference (updated 2026-10-31)

- These draft texts are housed in the repo for the AI assistant to
  reference and present to a paying customer.
- They are NOT added to public site navigation. The public Law
  Library's 5 finished PDFs remain in `printables/` separately.
- Installed 2026-10-31 (first batch, 20): 11 legal templates (fee
  waiver, tort claim, CPRA appeal, expungement guide, grand-jury
  complaint, declaration, attorney file request, Marsden motion,
  police complaint, facility grievance, discovery request PC
  1054.1) and 9 fact sheets (police encounters, after an arrest,
  Marsy's Law, plea waivers, deadlines, jail rights, case timeline,
  case triage, documentation).
- Installed 2026-10-31 (movement-core batch, 6, Hana-researched
  from official sources, draft status): civil-rights complaint
  (42 U.S.C. 1983), writ of mandate (CCP 1085), Pitchess motion
  (Evid. Code 1043-1045), suppression motion (Pen. Code 1538.5),
  habeas corpus petition (Pen. Code 1473; 28 U.S.C. 2254), CPRA
  enforcement writ (Gov. Code 7923.000 et seq.).
- Installed 2026-10-31 (appeals batch, 1, Hana-researched, draft
  status): notice of appeal with opening-brief outline — California
  civil/criminal and federal civil/criminal deadlines (CRC 8.104,
  8.308, 8.853, 8.822; FRAP 4), record designation, and post-notice
  steps. CPRA orders are excluded: they are writ-reviewed under
  Gov. Code 7923.500, not by ordinary appeal.
- Status: DRAFT texts, not finished PDFs and not legal advice.
  Where a court requires its own official form, the template says
  so — use the official form. Check current law and local court
  rules before filing.
- All material is general legal information only, not legal advice.
