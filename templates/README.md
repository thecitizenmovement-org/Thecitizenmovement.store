# Templates — backend, assistant-only reference (updated 2026-10-31)

- These draft texts are housed in the repo for the AI assistant to
  reference and present to a paying customer.
- They are NOT added to public site navigation. The public Law
  Library's 5 finished PDFs remain in `printables/` separately.
- Installed 2026-10-31 (first batch, 20): 11 legal templates and 9
  fact sheets (see prior README versions for the full list).
- Installed 2026-10-31 (movement-core batch, 6): civil-rights
  complaint (42 U.S.C. 1983), writ of mandate (CCP 1085), Pitchess
  motion (Evid. Code 1043-1045), suppression motion (Pen. Code
  1538.5), habeas corpus petition (Pen. Code 1473; 28 U.S.C. 2254),
  CPRA enforcement writ (Gov. Code 7923.000 et seq.).
- Installed 2026-10-31 (appeals batch, 1): notice of appeal with
  opening-brief outline (CA + federal deadlines).
- Installed 2026-10-31 (traffic batch, 3, in templates/traffic/):
  traffic forms index (TR-200, TR-205, TR-215, TR-220, TR-235,
  MC-031, CR-141-INFO, CR-142), trial-by-written-declaration
  statement draft for TR-205 (Veh. Code 40902), and trial de novo
  request guide for TR-220. These recreate the CONTENT and
  walkthroughs for the publicly shown Judicial Council forms —
  they do NOT replace the official forms. Use the official form
  from California Courts / the traffic clerk.
- Status: DRAFT texts, not finished PDFs and not legal advice.
  Where a court requires its own official form, the template says
  so — use the official form. Check current law and local court
  rules before filing.
- All material is general legal information only, not legal advice.
