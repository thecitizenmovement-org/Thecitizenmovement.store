California Rules of Professional Conduct, Rule 1.16(d))

DELIVERY DEADLINE AND METHOD

Please deliver the complete file to me within 14 days of the date of
this letter, at the address above. If the file is voluminous, contact
me within 7 days to arrange pickup or electronic delivery.

If you claim that any portion of the file is being withheld, identify
each withheld item in writing and state the specific legal basis for
withholding it.

NOTICE: California law prohibits conditioning release of a client's
file on payment of fees. If my file is not produced, I will file a
complaint with the State Bar of California.

Thank you for your prompt attention.

FILING NOTES: This is a letter, not a court filing -- send it directly
to the attorney. Keep a copy plus your certified mail receipt or email
confirmation. If 14 days pass with no response, send one follow-up
letter, then file a State Bar complaint at calbar.ca.gov (the complaint
form is free and can be filed online). If you need the file urgently
for a pending deadline, say so in the letter and shorten the deadline
to 7 days.
